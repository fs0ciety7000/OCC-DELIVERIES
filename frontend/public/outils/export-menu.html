Exporter un menu vers OCC

Récupère la carte d'un restaurant depuis la page que tu consultes (Uber Eats, Takeaway / Just Eat, ou le site du resto) et la transforme en fichier prêt à importer dans /admin.

1. Installer le favori

Affiche la barre de favoris (Ctrl/Cmd + Maj + B) puis glisse ce bouton dedans :

🔥 Exporter vers OCC

Préparation…

2. L'utiliser

  1. Ouvre la page d'un restaurant de Mons sur Uber Eats ou Takeaway (connecté·e ou non), attends qu'elle soit entièrement chargée et fais défiler jusqu'en bas si le menu se charge progressivement.
  2. Clique sur le favori 🔥 Exporter vers OCC : un encart affiche le nombre de catégories et de plats trouvés.
  3. Télécharger .json, puis dans /admin → Import : glisse le fichier, vérifie l'aperçu, confirme.
  4. Complète si besoin l'adresse / les coordonnées (bouton « géocoder ») et les frais de livraison.

Un restaurant à la fois, depuis ta propre navigation. Les options (tailles, suppléments) ne sont pas toujours exposées par les pages : ajoute-les dans l'éditeur de menu. Les prix restent indicatifs.

Le favori ne fait rien ?

Certains navigateurs bloquent les favoris JavaScript sur certains sites. Alternative : ouvre la console développeur (F12 → Console) sur la page du resto, colle ce code et valide.
